## Findings

### HIGH

#### [HIGH] R&D worker system prompt — doey.sh line count is wrong

The R&D worker system prompt (generated by `write_worker_system_prompt()` or injected context) states doey.sh is "1455 lines". Actual: **3042 lines** (more than double). CLAUDE.md itself does not state a line count, but the injected prompt context does.

**Recommendation:** Update the worker system prompt template to not hardcode line counts, or update to 3042.

---

#### [HIGH] R&D worker system prompt — "20 Doey skills" count is wrong

The injected context claims "20 Doey skills". Actual count: **22 doey skill directories** plus `unknown-task` and top-level `SKILL.md`/`CHANGELOG.md`.

Doey skills (22): `doey-add-window`, `doey-broadcast`, `doey-clear`, `doey-delegate`, `doey-dispatch`, `doey-kill-all-sessions`, `doey-kill-session`, `doey-kill-window`, `doey-list-windows`, `doey-monitor`, `doey-purge`, `doey-rd-team`, `doey-reinstall`, `doey-reload`, `doey-repair`, `doey-research`, `doey-reserve`, `doey-simplify-everything`, `doey-status`, `doey-stop`, `doey-watchdog-compact`, `doey-worktree`

**Recommendation:** Update the count to 22 (or 24 including `unknown-task` and top-level `SKILL.md`).

---

#### [HIGH] R&D worker system prompt — "13 hooks" count is wrong

The injected context claims "13 hooks". Actual count: **12 hook files** in `.claude/hooks/`:

`common.sh`, `on-pre-compact.sh`, `on-pre-tool-use.sh`, `on-prompt-submit.sh`, `on-session-start.sh`, `post-tool-lint.sh`, `session-manager-wait.sh`, `stop-notify.sh`, `stop-results.sh`, `stop-status.sh`, `watchdog-scan.sh`, `watchdog-wait.sh`

**Recommendation:** Update the count to 12.

### MEDIUM

#### [MEDIUM] context-reference.md:71 — Missing `/doey-rd-team` from skills list

The context-reference.md "Manager skills" list does not include `/doey-rd-team`, which exists as a skill directory. The `unknown-task` fallback skill is also undocumented.

**Recommendation:** Add `/doey-rd-team` to the Manager skills list. Document `unknown-task` as a fallback skill.

---

#### [MEDIUM] context-reference.md — Test Driver agent not in agent table

The `test-driver.md` agent exists in `agents/` (model: opus, color: red, memory: none) but is not in the agent definitions table in context-reference.md. CLAUDE.md mentions it in the architecture table but context-reference.md omits it.

**Recommendation:** Add test-driver to the agent definitions table.

---

#### [MEDIUM] README.md:62 — `doey 4x3` example could mislead

README shows `doey 4x3` as the CLI example for static grid. CLAUDE.md says "Static grid default: 3x2 (6 workers)". The test suite defaults to `3x2`. Using `4x3` as the example could mislead users about the default.

**Recommendation:** Change to `doey NxM` or `doey 3x2` to match the documented default.

---

#### [MEDIUM] README.md:53 — `doey remove` description incomplete

README says: `doey add / remove — Add/remove worker columns`

But `doey remove` is also used to unregister projects (by name). The help text in doey.sh says: `remove — Unregister a project (by name) or worker column (by number)`

**Recommendation:** Update README to reflect dual purpose.

---

#### [MEDIUM] CLAUDE.md — Missing `doey-rd-team` and `unknown-task` from documentation

CLAUDE.md does not mention the `doey-rd-team` or `unknown-task` skills anywhere.

**Recommendation:** Document if intended for use.

---

#### [MEDIUM] context-reference.md:93 — session.env variable list may drift

The `session.env` variable list is manually maintained. Variables are dynamically written by `_launch_session_core()` and related functions. Risk of list going stale as code evolves.

**Recommendation:** Add a comment in the code or a periodic verification step.

---

### LOW

#### [LOW] docs/linux-server.md:44 — fnm PATH inconsistency with linode-setup.md

Linux server systemd example uses `%h/.fnm/aliases/default/bin`, but linode guide uses `%h/.local/share/fnm/aliases/default/bin`. Actual fnm install path may vary.

```
linux-server.md: Environment=PATH=%h/.fnm/aliases/default/bin:...
linode-setup.md: Environment=PATH=%h/.local/share/fnm/aliases/default/bin:...
```

**Recommendation:** Standardize to match actual fnm default install path (`~/.local/share/fnm`).

---

#### [LOW] README.md — `/doey-rd-team` missing from slash commands list

The slash commands expandable section lists skills by category but omits `/doey-rd-team`.

**Recommendation:** Add to appropriate category.

---

#### [LOW] README.md:96 — Troubleshooting could mention `doey dynamic`

"Terminal too small → Use `doey 3x2`" is correct but could also mention `doey dynamic` as a more flexible alternative for small terminals.
